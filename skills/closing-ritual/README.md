# closing-ritual

## Problem

Agents quietly swallow assumptions made along the way — the user finds them in review, or in prod.

## What it does

Before work is accepted, the agent self-reports **doubts** (least-confident items), **blind spots** (context the user hasn't thought to ask about), and **unverified** claims — each traced to evidence or cut.

## When to install

Install when you want a structured self-report before accepting agent work — invoke with "wrap up", "closing ritual", or "before I accept this".

```bash
npx skills add lucavb/skills --skill closing-ritual
```

## Prerequisites

None. Works with any agent that supports skills.
