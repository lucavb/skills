# Citation audit

Use this branch when the prose contains citations or links.

- Open every link and resolve every DOI or other identifier.
- Confirm that title, author, date, and identifier describe the same work.
- Read the supporting passage. It must support the adjacent claim, not merely
  discuss the same broad topic.
- Give a page, section, timestamp, or equally useful locator for long sources
  when available.
- Keep only relevant, unique, correctly formed links that the reader can verify.
- Make citation placement unambiguous and follow the target venue's format.

**Done when:** every citation exists, identifies the intended source, supports the
attached claim, and gives the reader a practical way to verify it.
